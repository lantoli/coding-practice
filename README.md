# Coding practice

Personal programming exercises, competition solutions, and learning examples.

| Folder | Contents |
| --- | --- |
| [google-code-jam](google-code-jam/) | Google Code Jam, Facebook Hacker Cup, and other contest exercises from the original Google-Code-Jam repository. |
| [codejam-python](codejam-python/) | Google Code Jam and other contest solutions in Python. |
| [advent-of-code](advent-of-code/) | Advent of Code solutions, organized by year and language. |
| [tuenti-challenge](tuenti-challenge/) | Tuenti Challenge solutions from 2013 and 2014. |
| [codemotion-2012](codemotion-2012/) | Java examples from CodeMotion 2012. |

## Working with the projects

Each folder keeps its original project layout, data files, and documentation. Open
or run an individual project from its own directory; there is no shared build for
the whole collection. Some examples use older language and toolchain versions.

Dependency-update configuration at the repository root targets the Advent of Code
TypeScript project. Original project configuration files are also retained in
their respective folders.
