# Coding practice

Programming exercises organized by **competition → year → round/problem**.
Language folders sit inside a problem when there are multiple implementations.

| Folder | Contents |
| --- | --- |
| [google-code-jam](google-code-jam/) | Google Code Jam solutions in Java, Scala, Python, and C++. |
| [facebook-hacker-cup](facebook-hacker-cup/) | Facebook Hacker Cup solutions and round materials from 2011–2016. |
| [advent-of-code](advent-of-code/) | Advent of Code solutions from 2021–2025. |
| [tuenti-challenge](tuenti-challenge/) | Tuenti Challenge solutions from 2013 and 2014. |
| [practice](practice/) | General examples, exercises, and reusable templates. |

For example, Java and Python implementations of Alien Language live together under
[`google-code-jam/2009/qualification/alien-language/`](google-code-jam/2009/qualification/alien-language/).

## Running exercises

Run an exercise from its own project or language folder, following the local README.
Original source files, data files, and internal project layouts are kept together.
Some folders include reference implementations in additional languages, and some
solutions are unfinished. Older exercises may require older toolchains.

Repository automation lives in [.github](.github/). Dependency updates currently
target the Advent of Code projects. There is no shared build for the collection.

## Origin

This repository was renamed from `lantoli/Google-Code-Jam` to `lantoli/coding-practice`.
Exercises from `codejam-python`, `AdventOfCode`, and `TuentiChallenge` were imported
as file snapshots in September 2026 and organized by competition.
